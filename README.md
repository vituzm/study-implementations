# Study Implementations

This repository contains personal implementations of data structures and algorithms created for study purposes.

## Projects

- [AVL Tree](avl-tree/README.md) — An interactive AVL binary search tree implementation in Java.

## Requirements

- IntelliJ IDEA or another Java-compatible IDE
- A JDK that supports Java compact source files and the `IO` API used by `avl-tree/src/Main.java`

## Running a Project

Open the repository folder in IntelliJ IDEA, select the desired module, and run the project entry point. Refer to each project's README for implementation and command details.
